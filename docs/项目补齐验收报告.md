## 1. 验收结论

本轮任务书要求的 P0 代码闭环已补齐并通过本地验收：

- Agent 有独立的 7 场景离线控制层评测，并可从 `/api/eval/agent` 返回结果。
- 退款确认从进程内 JSON 改为数据库结构化人工审核记录，服务重启/多实例不依赖本地文件。
- AI 建议状态拆开为 `pending / accepted / rejected / auto_sent / legacy_sent`；Dashboard 采纳率只统计坐席建议，不把买家自动回复当成采纳。
- 知识缺口只有知识文档写入且索引成功时才会进入 `resolved`；索引失败返回 503 并保留 `pending`。
- RAG 评测字段由 `answer_accuracy_rate` 改为 `keyword_coverage_rate`，逐题字段改为 `keyword_coverage_ok`，前端同时说明这不是生成答案正确率。
- 当前正式评测集仍是 40 题；旧 67 题仅保留为历史归档。

## 2. 可复核的修改点

### 2.1 Agent 独立评测

- 用例：`eval/agent_cases.json`，7 个确定性场景。
- 运行器：`backend/app/services/agent_eval_runner.py`。
- API：`POST /api/eval/agent`。
- 页面：`frontend/src/pages/Evaluation.jsx` 的“运行 Agent 评测”按钮。
- 评测边界：实际计划由本地规则从输入推导，再与期望工具序列/参数对比；不调用外部大模型，因此报告不宣称真实 LLM 工具选择准确率。

最近一次结果：

| 指标 | 结果 |
|---|---:|
| 用例数 | 7 |
| 工具序列准确率 | 100.0% |
| 参数准确率 | 100.0% |
| 高危漏放 | 0 |
| 误转 | 0 |
| 完整任务通过率 | 100.0% |

### 2.2 结构化人工审核

- 新表：`human_review_actions`，模型文件 `backend/app/models/human_review.py`。
- 字段覆盖：租户、会话、动作类型、确认单详情、JSON payload、`pending/confirmed` 状态、创建/解决时间。
- `agent_loop.py` 生成退款确认卡时写表；确认接口按租户和状态查询，确认后写 `resolved_at` 并把会话切到 `waiting_human`。
- `pending_confirmations.json` 不再参与运行时读写。

### 2.3 AI 建议采纳口径

- 模型字段：`messages.suggestion_status`。
- 新建议默认 `pending`；买家端自动回复为 `auto_sent`；坐席采纳为 `accepted`；拒绝保留记录并标记 `rejected`，且不再展示给买家；无法判断的旧已发送数据迁移为 `legacy_sent`。
- 迁移：`backend/app/services/schema_migrate.py` 为旧 SQLite 表补列并回填兼容状态。
- 统计：`backend/app/routers/stats.py` 只以 `pending/accepted/rejected` 作为坐席建议分母，`accepted` 才计入采纳数。

### 2.4 知识缺口闭环

- `resolve_gap` 不再吞掉索引失败。
- `index_document` 返回失败或抛异常时，缺口保持 `pending`，接口返回 503 和明确原因；前端/坐席可以重试。
- `create_doc=false` 不允许伪装成已解决，因为没有可被检索的知识证据。

### 2.5 RAG 指标口径

- API/Schema/UI 全部改成 `keyword_coverage_rate`、`keyword_coverage`。
- 页面提示：“仅代表检索文本覆盖，不等于生成答案正确”。
- 这仍是低成本代理指标，不能替代人工标注或 LLM-as-judge。

## 4. 尚未宣称完成的边界

- 本轮没有重新部署阿里云服务器，也没有自动提交/推送 GitHub。
- 没有在未获授权的情况下调用真实外部 LLM 批量评测；线上模型真实工具选择准确率仍未知。
- RAG 的 40 题评测需要线上知识库索引可用后再跑；本轮验证的是题库/报告结构和字段口径，没有把 mock 结果写成线上 RAG 数字。
- 订单查询、退款试算仍是演示 mock，不代表真实订单、支付或退款执行。
- `data/faiss/` 是本地集成测试启动时生成的运行时索引目录，不作为业务成果数字。
